ESP32 / ESPHome dependency

This Homebridge plugin is designed to work with the Balboa-GS100-with-VL260-topside ESPHome project by kgstorm. That project provides the ESP32 hardware interface and ESPHome entities for communicating with compatible Balboa VL-series topside controllers.

This plugin connects to those ESPHome entities through the ESPHome native API and exposes spa controls to Apple HomeKit through Homebridge.
